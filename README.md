# 🍔 Minute Burger — Kitchen Display System

Custom order tracking & kitchen display app for Minute Burger stores.

## Features
- ✅ Shift login (Morning: 1111, Swing: 2222, Graveyard: 3333)
- ✅ Order entry with all products
- ✅ Adjustable preparation time per ticket
- ✅ Drag & drop: Preparing → Ready
- ✅ Special instructions (clickable list, no typing needed)
- ✅ Color timer: Green → Yellow → Red
- ✅ Auto-remove from Ready after 2 minutes
- ✅ Order tracker / history log
- ✅ Resets ticket # daily at midnight

## How to Use
1. Open `index.html` in browser
2. Enter shift PIN
3. **Order Entry** tab: Select products → adjust time if needed → Submit
4. **Kitchen Display** tab: Drag ticket from Preparing to Ready when done
5. **Tracker** tab: View all orders & status

## Products
- **Sulit**: MB, DMB, CB, DBM — Buy 1 Take 1
- **Chicken**: CT, DCT — Buy 1 Take 1
- **Hotdog**: CD, BH, FO — Buy 1 Take 1
